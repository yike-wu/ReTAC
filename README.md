# ReTAC project page

This is a dependency-free static project page. Open `index.html` locally, or deploy the directory with GitHub Pages, Netlify, Vercel, or any static host.

Before publishing, edit `site.config.js`:

1. Replace the author and affiliation placeholders.
2. Replace `TODO` in the BibTeX entry.
3. Paste the arXiv URL after the paper is announced; this reveals the arXiv button.
4. Optionally add a public code repository URL.

`assets/ReTAC.pdf` is the public author version supplied for release. Replace it with the final arXiv PDF when the submission is announced.

## GitHub Pages

Create a public GitHub repository named `retac` under the `yike-wu` account, upload these files to its default branch, then enable **Settings → Pages → Deploy from a branch**. The page will be served from the repository root at `https://yike-wu.github.io/retac/`.
